# Submission source links

Submit the UI and server source as separate components:

| Component | Source location | Repository link |
|---|---|---|
| Frontend / user interface | [`frontend/`](../frontend/) — React and Vite application, screens, reusable UI components, and API client | [Frontend source on GitHub](https://github.com/nikhatmulla2004-afk/rental_listing/tree/main/rental-service/frontend) |
| Backend / API | [`src/main/java/`](../src/main/java/) — Spring Boot controllers, services, repositories, entities, and DTOs | [Backend source on GitHub](https://github.com/nikhatmulla2004-afk/rental_listing/tree/main/rental-service/src/main/java) |
| Wireframes | [`wireframes.md`](./wireframes.md) — screen layouts and end-to-end user flows | [Wireframes in repository](https://github.com/nikhatmulla2004-afk/rental_listing/blob/main/rental-service/docs/wireframes.md) |
| Database design | [`database-design.md`](./database-design.md) — ER diagram and table structures | [Database design in repository](https://github.com/nikhatmulla2004-afk/rental_listing/blob/main/rental-service/docs/database-design.md) |

Use the frontend link for the **Frontend Code** component and the backend link for the **Backend Code** component. The frontend and backend are in the same repository but are different directories. The `main` links identify the repository paths; include the working branch or commit containing the latest changes when submitting.
